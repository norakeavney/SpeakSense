# SpeakSense Frontend

Next.js frontend for the SpeakSense speech analysis platform.

## Features

- 🎤 Audio file upload
- 📝 Speech-to-text transcription (coming soon)
- 👥 Speaker identification (coming soon)
- 😊 Emotion detection (coming soon)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Tech Stack

- **Next.js 14** - React framework
- **Tailwind CSS** - Styling
- **React 18** - UI library

## API Integration

The frontend connects to the Django backend running on `http://127.0.0.1:8000/api`

Make sure the backend server is running before starting the frontend.
